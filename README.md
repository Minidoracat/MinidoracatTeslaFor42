# Minidoracat Tesla Collection

特斯拉電動車與充電設備：用電池行駛、在充電座充電，附特斯拉風格儀表、哨兵與露營模式

Project Zomboid Build 42 MOD。

2026-10-29 首發到 Steam Workshop：[Minidoracat Tesla Collection](https://steamcommunity.com/sharedfiles/filedetails/?id=3829501237)（ID 3829501237）。

## 功能

- **兩台車**：Model Y Performance 與 Model 3 Performance，各 8 種原廠車色；停車格都會出現，高級住宅區只有 Model Y。車門、尾門（Model 3 是行李廂蓋）與前蓋照實車打開，車窗透明看得到車內，用特斯拉原廠錄音的馬達聲。
- **電池與續航**：高電壓電池的電量取代汽油，開車耗電、煞車回收；充滿電和原版同級車加滿一箱油跑得一樣遠（沙盒「續航倍率」可調，也跟著原版「耗油量」增減）。
- **第三代壁掛式充電座與充電線**：電工 3 級學會配方，裝上有市電的牆（停電後改用附近發電機的電），右鍵插上充電線；11.5 kW，從沒電充到 90% 約 6 小時（沙盒「充電速度倍率」可調）。用發電機的電就會耗油，插著線時車上的空調、露營用電也算；充滿一台約用一桶（沙盒「充電耗油倍率」可調），市電不耗油。插著線開不走，車被拖走會自動拔線。充電卡顯示功率、已充多少與剩餘時間，可調目標電量。
- **第三代行動充電器**：放在地上就能用，徒手放下和撿起；7.6 kW、線長 5 格，從沒電充到 90% 約 9 小時。放在有電的室內（市電，或發電機供電的建築）時照壁掛式的規則；其他地方要放在運轉中的發電機旁 2 格內，直接插在發電機上。耗油和壁掛式一樣：不論放在室內或直接插，用發電機的電充滿一台約用一桶。撿得到（機率約為車電池充電器的一半）、電工 2 級用車電池充電器改裝，新生成的特斯拉也有四分之一的機率在後行李廂附一組。
- **特斯拉風格儀表**：取代原版儀表，顯示檔位、車速、電量、續航與即時耗電；電源鍵、點車子俯視圖開關車門、提醒膠囊、每個按鈕的停留說明；V 鍵圓盤選單多了露營模式與查看充電狀態。
- **卡片鑰匙與手機鑰匙**：特斯拉的車鑰匙變成卡片鑰匙，車外感應上鎖解鎖；新物品「智慧型手機」設為手機鑰匙後，走近拉門就解鎖、放袋子裡也能發動、走遠自動上鎖；一支手機可以配對多台特斯拉。
- **沒有鑰匙時**（沒裝綁車 MOD）：車沒上鎖時誰都能插拔充電線；車鎖著時要有這台車的鑰匙，選單變灰並寫「車鎖著，要有這台車的鑰匙」。短接發動過的車和鑰匙插在點火孔上一樣，能插拔線、開露營，坐在車上也能把手機設為手機鑰匙。充電座的主人（放下它的人、所在安全屋的屋主與成員）可以拔自己座上的線。
- **手機 Tesla App**：首頁車況與照車漆的車圖、上鎖解鎖、閃燈、鳴喇叭、開關前行李廂與尾門、找車與世界地圖、哨兵開關與警報紀錄、充電狀態、切換車輛；有電網不限距離，停電後只剩藍牙 30 公尺，連不到時顯示最後紀錄。手機可以拖到畫面上任何位置，下次打開還在那裡。
- **召喚**（要裝 AutoDrive 與自動駕駛模組）：App 叫空車「到我這裡」、開到地圖上選的地點，或直直前進／後退。
- **哨兵模式**：鎖車後開啟；有人碰車閃燈並通知車主，砸窗、短接、拆零件響原版警報；車主離線時下次上線補送。
- **露營模式**：停車時空調照常運作並自動冷暖，在車上睡覺算一般床，車上插座幫電池充電，車內燈亮起；電量低於下限（沙盒「露營模式電量下限」，預設 20%）自動關閉。
- **驅動單元零件**：特斯拉的驅動單元改用專用零件修理，可以從別台特斯拉拆或用電工 4 級的配方做。
- **和家族 MOD 連動**（都是選裝，執行期偵測）：Vehicle Manager（綁定的車照它的權限、車輛管理選單可以打開 App、車主沒卡片也能設新手機）、MiniMap（小地圖畫出你的特斯拉、App 導航到車）、AutoDrive（召喚；它的卡片擺在特斯拉儀表上方）。

完整說明與常見問題見 Steam 指南稿 [STEAM_GUIDE.md](STEAM_GUIDE.md)（英文 [STEAM_GUIDE_EN.md](STEAM_GUIDE_EN.md)）。

## 多人身分的限制

- 哨兵、露營的車主通知與離線通知以帳號名認人；通知裡的闖入者（「玩家 X」）也是同一套帳號名，認不出帳號的寫「身分未確認的玩家」。Steam 伺服器上，帳號名在角色建立或上線後一遊戲分鐘內綁定那位玩家的 Steam 帳號，之後別的 Steam 帳號用同一個名字收不到通知，也不會以那個名字出現在別人的通知裡；no-steam 伺服器沒有可以比對的帳號，無法防止冒名。
- 分割畫面的第二～四位玩家不算任何帳號（帶著鑰匙時照常能用車；碰別人的車時通知寫「身分未確認的玩家」）。裝了綁車 MOD 時，被綁定的車照綁車 MOD 的規則，分割畫面玩家刷卡、開關哨兵都用不了。
- 還沒綁定的名字，改過的客戶端有機會搶先綁定。搶到的名字底下沒有特斯拉的通知可拿，但那位玩家之後收不到通知，搶到的人碰車時通知也會寫那位玩家的名字；本 MOD 沒有管理員改綁的功能。
- 名字還沒綁定、底下卻已經存著離線通知的玩家（例如伺服器先以 no-steam 開過再改成 Steam，或從舊版升級時還有沒領的離線通知），要建立新角色才會綁定；在那之前他完全收不到特斯拉通知，自己開的哨兵、露營也不算車主開的。
- Steam 好友連線（由玩家主持的合作遊戲）的登入名就是 Steam 顯示名稱，遊戲不驗證：還沒綁定的名字，誰先用它加入就綁給誰。
- Steam 好友連線時同一個顯示名稱可能同時在線兩位：手機 App 召喚只認 Steam 帳號綁定這個名字的那位；另一位自己開始的召喚，在連線範圍外停不了，App 也顯示成別人在召喚。玩家改了 Steam 顯示名稱後，以前記在舊名字下的通知、哨兵與露營也不再算他的。
- 遊戲本身登入流程的已知問題（需要改過遊戲程式的客戶端）也可能讓還沒綁定的名字被綁走；已綁定的名字不受影響。

## 安裝

- Steam Workshop：[Minidoracat Tesla Collection](https://steamcommunity.com/sharedfiles/filedetails/?id=3829501237)（ID 3829501237）
- 手動安裝：把 `MOD/MinidoracatTeslaFor42/Contents/mods/MinidoracatTeslaFor42` 整個資料夾複製到 `%USERPROFILE%\Zomboid\mods\`

## 開發

- `link_workshop.bat`：手動同步、唯讀狀態與歸檔卸載；MOD 以實體副本放入 `Zomboid\Workshop\` 與 `Zomboid\mods\`，不使用目錄連結
- `PZ_Test.bat`：暗色點選視窗，啟動前增量同步目前 MOD 與家族依賴；首次預設 no-Steam，之後記住各專案的選擇。需要換檔但遊戲仍在執行時拒絕同步與新啟動，不停止既有遊戲；完整驗證與資料邊界見 `../pz-family-docs/tools.md`
- `Publish_Workshop.bat`：發布到 Steam Workshop（需 Steam 用戶端已登入；可選擇只更新內容／封面／簡介；首發仍走遊戲內上傳器）

## 版本
